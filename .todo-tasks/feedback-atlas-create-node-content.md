# Create an Atlas node with its content in one action

## What happened

I used the Atlas MCP to add explanatory nodes to an Atlas document. Adding a node and giving it Content required two ordered batch actions: first add the Node, then set its Content. I had to assemble a long, repetitive batch just to create several fully described nodes.

## Why it matters

Atlas nodes are most useful when their explanatory content travels with their creation. Splitting that one conceptual action increases authoring ceremony and makes a large batch easier to mistype or partially misunderstand.

## Direction

Consider whether node creation can accept authored Content directly while retaining the existing data-file behavior.
