# Principles

Nylon represents the workings of a software system as hierarchical data because
a user needs different amounts of information to answer different questions.

Nylon's main purpose is to let the user build the view they need to understand
the software they are working on. The system does not prescribe one complete
view as the answer to every question.

Nylon develops two complementary capabilities:

- A formalism keeps each view structurally meaningful to people and agents.
- Interface tools make useful views easy to construct, revise, and navigate.

These principles guide product decisions that detailed requirements do not
settle. They do not exhaust Nylon's intended behavior.
