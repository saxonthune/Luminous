# Idea

Atlas is a Luminous app (doc01.04) for software design. One canvas holds a
visual representation of all of the essential features of a piece of software,
such that a human can comprehend it and an agent can read and edit it. The
inspiration is a Bruegel or Bosch painting: a wealth of detail the user pores
over and digests at their own speed.

The starting point is the Dataflow Designer's Box (doc01.05.01): a mix of
intention written as prose and language-specific contracts (JSON, traits, and
similar).

Atlas adds inventories of interfaces. A section holds a program's interface
surface — for example, a CLI split into its subcommands. From an entry in the
inventory, the user sees the dataflow that happens when a user enters that
command: the input parameters are a source; the command is traced across
filters and switches — each a business rule — and across the other sources
pulled into the flow; the flow is followed to all of the writes.

An atlas is authored over time, and not regenerated by pipeline scripts (which
would be a transduction of code to visual artifact). Instead, the atlas can be
compared against generated artifacts or source code itself.

The first Atlas canvas is a rough draft of braincrawl (doc01.07.02), drawn to
find out what Atlas is by drawing one.
