# A document without diagrams

Luminous Portable renders **ordinary Markdown**. A Mermaid block is optional.

## Notes and decisions

This sample exercises prose, *emphasis*, `inline code`, lists, quotes, tables,
and ordinary code fences without creating any canvases.

- Read the explanation.
- Review the alternatives.
- Record a decision.

> A useful document can stand on its own without a diagram.
